# AXON Desktop

AI-powered delivery pipelines in an Electron desktop app. Runs Claude-integrated pipeline execution locally.

## Prerequisites

- **Git** — required for repository operations
- **Node.js 20 or 22** — Electron binary scripts require these versions
- **npm** or **yarn**

## Development Setup

```bash
# Install dependencies
npm install

# Terminal 1: Start dev server (React/Vite on port 5173)
npm run dev
```

This runs Vite in dev mode and Electron in watch mode.

## Building for Production

### Build artifacts (renderer + Electron main)
```bash
npm run build
```

Outputs:
- `dist/` — React app (HTML, JS, CSS)
- `dist-electron/` — Electron main process (CommonJS)

### Build installers

**Windows:**
```bash
npm run build:win
```
Generates: `release/AXON-Setup-x64.exe` (NSIS installer)

**macOS:**
```bash
npm run build:mac
```
Generates: `release/AXON-*.dmg` (for both x64 and arm64)

**Both platforms:**
```bash
npm run build:all
```

## Icons

Icons are in `build/`:
- `icon.png` — AXON logo (copied from `src/assets/axon-icon.png`)
- `icon.ico` and `icon.icns` are auto-generated by `electron-builder` from `icon.png`

To update branding: replace `build/icon.png` with a new 512×512 PNG.

## What Gets Generated

The `/release` directory contains:
- **Windows:** NSIS installer (`.exe`) for x64 architecture
- **macOS:** DMG disk image for x64 and arm64 (Apple Silicon)

Installers can be distributed and run on user machines without additional setup.

## Troubleshooting

**Build fails with "Cannot find module":**
- Run `npm install` again
- Ensure Node.js version is 20 or 22

**Electron app won't start in dev:**
- Kill any existing `electron` processes
- Verify Vite is running on port 5173
- Check that `dist-electron/main.js` was compiled

**"Cannot create symbolic link" during installer build (Windows):**
- This error occurs when extracting code-signing tools during the build
- **Solution 1 (Recommended):** Run the terminal as Administrator
- **Solution 2:** Enable Developer Mode on Windows 11:
  - Settings → System → For developers → Developer Mode (toggle on)
  - Allow creating symbolic links without Admin
- **Solution 3:** Clear the cache and retry:
  ```bash
  rm -r $env:LOCALAPPDATA\electron-builder\Cache
  npm run build:win
  ```

**Installer creation fails on macOS:**
- Verify `build/icon.png` exists (512×512)
- Ensure Xcode command line tools are installed: `xcode-select --install`
- May need to build on macOS if cross-compiling from Windows
